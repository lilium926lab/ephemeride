Éphéméride — キャラクター誕生日アルマナック
==========================================

■ 中身
  index.html            アプリ本体
  manifest.webmanifest  ホーム画面用の設定（名前・アイコン・配色）
  sw.js                 オフラインで開けるようにする仕組み
  icons/                アイコン（192 / 512 / maskable / apple-touch 180）
  splash/               iPhone用の起動画面（13サイズ）

■ ホーム画面に追加する手順
  1. このフォルダをまるごと、Reliquaire と同じ置き場所にアップロードします。
     （GitHub Pages / Netlify / Cloudflare Pages など、どこでも構いません）
  2. スマホの Safari でその URL を開きます。
  3. 共有ボタン → 「ホーム画面に追加」。
     アイコンと「Éphéméride」の名前が付いた状態で追加されます。
  ※ Android の Chrome なら メニュー → 「アプリをインストール」。

■ データの保存について
  入力した内容は、その端末のブラウザ内（IndexedDB）に自動保存されます。
  サーバーには何も送信されません。
  端末を変えるとき・バックアップを取るときは、
  「JSON書き出し」でファイルに保存し、移動先で「読み込み」してください。

■ 更新するとき
  index.html を新しいものに差し替えれば、次にオンラインで開いたときに反映されます。
  （ページ本体はネット優先で読み込む設定にしてあります）
